# Stock Quest

> Gamified D&D-inspired retro RPG trading dashboard for Coinbase Tokenized Stocks on Base Network. Built for the Base Latam Builder Quest.

## Overview

Stock Quest reimagines decentralized finance and tokenized stock trading by applying classic tabletop RPG and 16-bit arcade mechanics:
- **Character Sheet Portfolio**: Your liquid balance is your MP, your drawdown buffer is your HP, and your portfolio performance drives your level progression.
- **D20 Trade Execution**: Every buy and sell order rolls a 20-sided die (d20). Natural 20s grant arbitrage discounts and massive XP, while drawdowns award Battle Scar XP to reward learning risk management.
- **D&D Financial Attributes**: STR (Alpha), DEX (Execution Speed), CON (Drawdown Resilience), INT (Diversification), WIS (Stop-loss Discipline), and CHA (Guild Influence).
- **Coinbase Tokenized Stocks on Base**: Real-time representation of tokenized equities (COIN, AAPL, NVDA, TSLA, MSFT, AMZN, SPY, MSTR) as epic equipment.
- **Quest Board & Leaderboard**: Complete trading milestones to claim gold and XP rewards, and compete on the Base Network Hall of Fame.
- **Procedural 8-bit Audio & CRT Filter**: Retro sound synthesizer using Web Audio API and toggleable arcade scanlines.

```text
stock-quest/
├── index.html              # Main application entry point
├── assets/                 # 16-bit retro sprites and banners
│   ├── title.jpg           # Title screen banner (Built on Base)
│   ├── hero.jpg            # Adventurer character sprite
│   ├── shopkeeper.jpg      # Tavern merchant NPC sprite
│   └── d20.jpg             # Glowing 20-sided dice sprite
├── css/
│   ├── tokens.css          # Design tokens, palette, and CRT scanlines
│   ├── components.css      # Retro frames, buttons, meters, badges, and modals
│   └── screens.css         # Screen layouts and responsive views
├── js/
│   ├── audio.js            # Procedural 8-bit sound effects (Web Audio API)
│   ├── data.js             # Tokenized stocks catalog, initial stats, quests
│   ├── engine.js           # Core D&D engine: d20 rolls, XP system, buy/sell logic
│   └── app.js              # Application controller and UI coordinator
└── graphify-out/           # Knowledge graph generated by Graphify
    ├── graph.html          # Interactive D3 knowledge graph visualizer
    └── graph.json          # Node and edge topology structure
```

## Running Locally

1. Open a terminal in the project directory:
   ```bash
   cd stock-quest
   ```

2. Start any static HTTP server (e.g. Python):
   ```bash
   python -m http.server 8080
   ```

3. Open your browser at:
   `http://localhost:8080`
